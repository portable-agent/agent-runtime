# Agent Runtime

Agent Runtime — stateless-сервис, который превращает текст пользователя в предложение действия.
Результат передаётся в `action-service`, где выполняются подтверждение, исполнение и аудит.

## Ответственность

Сервис отвечает за:

- приём текста и контекста;
- вызов внешней AI-модели через repository-адаптер;
- получение уровня риска через policy-адаптер;
- создание типизированного предложения.

Сервис не отвечает за:

- исполнение действий;
- OAuth-токены коннекторов;
- платежи и календарные операции;
- долговременное хранение данных;
- окончательное решение о безопасности действия.

Текущие `DemoModelRepository` и `DemoPolicyRepository` работают только локально. Их правила —
техническая заглушка, а не согласованное поведение продукта.
